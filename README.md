# Curse-Cycle (Five Day Challenge)

**Curse-Cycle** — это мод для Minecraft (Fabric, 1.21.1), в котором каждые 5 игровых дней случайным образом выбирается и активируется новое испытание, меняющее привычный игровой процесс.

Испытание **«Голый король»** (`armor_disabled`, MEDIUM/GLOBAL) отключает защиту
брони и полёт на элитрах, сохраняя предметы в слотах. Активация:
`/fdc activate armor_disabled`. [Сценарии проверки](docs/armor-disabled-testing.md).

Испытание **«Водобоязнь»** (`floor_is_water`, MEDIUM/GLOBAL) мгновенно убивает
при касании стоячей или текущей воды. Creative и Spectator исключены;
дождь и вода в котлах безопасны. Активация: `/fdc activate floor_is_water`.
[Сценарии проверки](docs/floor-is-water-testing.md).

Испытание **«Пол — это лава!»** (`the_floor_is_lava`, HARD/GLOBAL) наносит
3 сердца урона при касании твёрдой опоры под стопами и затем каждые 20 тиков.
Лодки, вагонетки, полёт и плавание без опоры безопасны; Creative и Spectator
исключены. Активация: `/fdc activate the_floor_is_lava`.
[Сценарии проверки](docs/floor-is-lava-testing.md).

Испытание **«Только фонка не хватает»** (`slippery_hands`, EASY/GLOBAL) даёт
игрокам Survival и Adventure сцепление обычного льда на земле: после отпускания
клавиш остаётся инерция. Creative, Spectator, плавание, транспорт и полёт
сохраняют обычную физику. Активация: `/fdc activate slippery_hands`.
[Сценарии проверки](docs/slippery-hands-testing.md).

## Основные особенности и механики

1. **Согласованная система времени и интервалов:**
   - По умолчанию одновременно действует 1 испытание, сменяющееся каждые 5 игровых дней (120,000 тиков).
   - Поддерживает сон (пропуск ночи), серверные команды изменения времени (`/time set/add`), перезапуски сервера и переподключение игроков без повторных/пропущенных срабатываний.
   - Новое испытание выбирается и анонсируется Колесом за 1 игровой день (24,000 тиков) до активации. Текущее испытание продолжает действовать до момента смены.

2. **Специальное испытание «Два испытания одновременно»:**
   - В пуле присутствeт специальное испытание `double_challenge` («Два испытания одновременно»).
   - При его выпадении система выбирает 2 различных обычных испытания, действующих одновременно весь 5-дневный период. По истечении периода оба завершаются, и цикл возвращается к обычному режиму.

3. **Точное Колесо Фортуны:**
   - Сервер полностью авторитарно выбирает результат и синхронизирует его со всеми клиентами.
   - Выбранный сектор визуально с абсолютной точностью совпадает со стрелкой-указателем (на 12 часов).
   - Сохраняет баланс сложностей (3 лёгких, 2 средних, 1 сложное), рост доли сложных испытаний, отслеживание исчерпания пула и исключение частых повторов.

4. **Завершение испытаний и очистка эффектов:**
   - При смене испытания отключаются все его эффекты (`onStop`, `onPlayerLeave`).
   - Отключение эффектов не восстанавливает потерянное здоровье или предметы.
   - Очистка и re-apply корректно работают при переподключении игроков и перезапуске сервера.

5. **Интерфейс (HUD & Главное меню `H`):**
   - **HUD Overlay:** Отображает номер дня, таймер до смены, текущие испытания с их краткой версией описания и сложностью, а также анонс следующего выпадения.
   - **Главное меню (Клавиша `H`):** 4 удобные вкладки:
     - *Активные* — текущие испытания с возможностью открыть полные правила.
     - *Следующее* — заанонсированное испытание.
     - *История* — удобный просмотр истории с пагинацией (страницами) для длительного прохождения.
     - *Настройки* — интерактивное управление отображением HUD, позицией X/Y и звуками колеса.

6. **Глобальные и персональные испытания:**
   - По умолчанию испытания глобальные для всех игроков.
   - Архитектура поддерживает персональные испытания (`Scope = PERSONAL`), привязанные к UUID игрока.

7. **Расширяемая архитектура событий:**
   - Базовый класс `Challenge` предоставляет готовые хуки событий: `onPlayerJump`, `onPlayerDamage`, `onBlockBreak`, `onBlockPlace`, `onItemUse`, `onEntityInteract`, `onPlayerJoin`, `onPlayerLeave`.
   - Логика отдельного испытания инкапсулирована внутри своего класса.

8. **Команды для разработки и тестирования (`/fdc` или `/cursecycle`):**
   - Изменяющие команды (`trigger_spin`, `activate`, `setday`, `reset`) требуют прав оператора уровня 2. Команды просмотра доступны всем.
   - `/fdc active` — показать список активных испытаний.
   - `/fdc next` — показать предварительно выбранное следующее испытание.
   - `/fdc trigger_spin` — принудительно запустить анимацию колеса фортуны и выбор испытания.
   - `/fdc activate <id>` — принудительно активировать испытание по его ID.
   - `/fdc list` — вывести полный список всех зарегистрированных испытаний.
   - `/fdc history` — посмотреть историю выпавших испытаний.
   - `/fdc setday <day>` — изменить текущий игровой день для проверки событий.
   - `/fdc reset` — сбросить время мира на день 1, историю, пул и маркеры циклов, затем сразу запустить первое испытание.

Настройки находятся в `config/cursecycle.json`. Значения `false` в `challengeToggles` исключают соответствующие испытания из выбора; отключённые сохранённые испытания заменяются после запуска сервера. Интервал должен быть положительным, а веса — тремя неотрицательными числами с ненулевой суммой. Некорректные значения заменяются безопасными значениями по умолчанию, время анонса ограничивается длиной интервала. Настройка «Анимация и звуки Колеса» отключает оба эффекта на текущем клиенте.

## Архитектура проекта

- `com.cursecycle.challenge` — абстрактный класс `Challenge`, `ChallengeDifficulty`, `ChallengeScope`, `ChallengeRegistry`.
- `com.cursecycle.challenge.special` — специальное испытание `DoubleChallenge`.
- `com.cursecycle.event` — централизованный диспетчер игровых событий `ChallengeEventManager`.
- `com.cursecycle.mixin` — миксин `PlayerEntityMixin` для фиксации прыжков.
- `com.cursecycle.config` — менеджер конфигурации `CurseCycleConfig`.
- `com.cursecycle.state` — сохранение состояния мира и персональных данных `CurseCycleState` (`PersistentState`).
- `com.cursecycle.roulette` — селектор испытаний `RouletteSelector`.
- `com.cursecycle.network` — CustomPayload API сетевая синхронизация (`NetworkHandler`).
- `com.cursecycle.client.gui` — клиентский HUD (`CurseCycleHudOverlay`), экраны `WheelScreen` и `MainMenuScreen`.

## Сборка и запуск

### Требования:
- Java 21 JDK
- Gradle 8.8+

### Команды:
- Сборка мода: `./gradlew build`
- Запуск тестового клиента: `./gradlew runClient`
- Запуск тестового сервера: `./gradlew runServer`
