# Curse-Cycle

Мод для Minecraft Java Edition 1.21.1 на Fabric: колесо выбирает случайные испытания, которые меняют правила выживания. Длительность испытания и время предупреждения о следующем настраиваются.

В моде 44 обычных испытания и специальное двойное. Ещё шесть служебных заглушек отключены по умолчанию. Все названия, ID и краткие правила — в [списке испытаний](docs/challenges.md).

## Установка

| Компонент | Версия |
| --- | --- |
| Minecraft Java Edition | 1.21.1; версия 1.21.11 не подходит |
| Java | 21 |
| Fabric Loader | 0.16.0 или новее; в проекте используется 0.16.0 |
| Fabric API | В проекте используется 0.102.0+1.21.1 |
| Curse-Cycle | 1.0.5 |

1. Создайте профиль Minecraft 1.21.1 с Fabric в CurseForge или другом лаунчере.
2. Откройте папку этого профиля и поместите Fabric API и `curse-cycle-1.0.5.jar` в `mods`.
3. Запустите профиль и войдите в мир. JAR распаковывать не нужно; файл с суффиксом `-sources.jar` устанавливать не следует.

Для сетевой игры установите одинаковую версию мода на сервер и всем игрокам. Мод использует собственные сетевые пакеты и клиентские механики камеры, управления и интерфейса.

## Как проходит игра

По умолчанию после первого входа в новый мир даётся **60 секунд подготовки**, затем первое колесо крутится **5 секунд**. После него начинается испытание длительностью **5 игровых дней**. За **1 игровой день до смены** следующее колесо показывает будущее испытание.

- Длительность испытания задаёт период смены. Колесо только выбирает и заранее показывает следующее испытание; текущее продолжает действовать до срока смены.
- Сон приближает смену через пропуск ночного времени. Срок отсчитывается от начала цикла, поэтому он не обязан совпадать с рассветом.
- Если длительность — 2 дня, а предупреждение — 1 день, первое испытание действует два дня, а второе объявляется за день до его замены.
- Начальная подготовка и первое колесо считаются в серверных тиках при наличии игроков. Сон и `/time` их не ускоряют. Прогресс сохраняется с миром.
- После начала цикла испытания сменяют друг друга без запланированного пустого периода, пока доступны включённые испытания. Старое пустое сохранение восстанавливается при обработке расписания.
- Изменения времени мира влияют на обычный цикл. При остановленном дневном времени (`doDaylightCycle = false`) его отсчёт тоже останавливается; механики испытаний с серверными таймерами продолжают работать.
- При завершении снимаются ограничения испытания. Потерянные предметы, здоровье и разрушенные блоки не возвращаются.

**Двойное испытание** выбирает два разных обычных испытания, действующих одновременно весь настроенный период. Для пары нужны хотя бы два доступных обычных испытания; при единственном доступном варианте включается только он.

## Колесо

Результат выбирает сервер. Клиент показывает его после остановки колеса или пропуска анимации; при отключённой анимации результат доступен сразу.

По умолчанию с первого дня в колесе 3 лёгких, 2 средних и 1 сложное испытание. С 20-го дня — 2/3/2, с 50-го — 1/2/3. Эти числа задают желаемое число секторов каждой сложности. Если одной сложности не хватает, колесо заполняется оставшимися испытаниями других сложностей. Повторяющиеся секторы появляются только при нехватке разных кандидатов во всём оставшемся пуле. Пул пополняется после полного исчерпания.

## Меню и HUD

Меню открывается клавишей **H**; назначение можно изменить в настройках управления Minecraft → Curse-Cycle.

| Вкладка | Содержимое |
| --- | --- |
| О моде | Правила, текущее расписание и управление |
| Активные | Действующие испытания и их полные правила по нажатию |
| Следующее | Результат последнего колеса |
| История | Прошлые выпадения |
| Команды | Справочник команд |
| Настройки | Расписание, показ и положение HUD, анимация и звуки колеса |

HUD показывает активные испытания, время до смены и объявленное следующее испытание. Когда осталось меньше игрового дня, время отображается в формате `ММ:СС`, например `03:22`; от одного дня — в игровых днях с округлением вверх. Таймер рассчитан по 20 тикам на секунду; сон и изменение времени мира меняют оставшееся время. F1 и настройка показа HUD скрывают панель.

У отдельных испытаний есть свои подсказки: заблокированное направление движения, шкала выносливости у «На массе», крестики на закрытых слотах инвентаря. В правилах «Пол — это лава!» постоянные безопасные поверхности показаны значками: кровати, шерсть, шерстяные ковры и снопы сена. Блоки, поставленные игроками во время текущего испытания, также безопасны в пределах временного учёта; после завершения или перезапуска сервера отметки сбрасываются. Опасный контакт наносит **3 единицы урона — полтора сердца** с интервалом в секунду. «Хрупкий пол» предупреждает об обрушении трещинами и нарастающим треском.

## Настройки и команды

Расписание можно изменить в меню без перезапуска: в одиночной игре — владельцу мира, на сервере — оператору уровня 2. Изменение длительности через меню начинает новый отсчёт от момента применения, сохраняя действующие испытания и уже объявленное следующее.

Файл настроек — `config/cursecycle.json` в папке профиля или сервера. Расписание относится к установке/серверу, а состояние цикла сохраняется отдельно в каждом мире. HUD и анимация настраиваются на клиенте. Подробности и все поля: [конфигурация](docs/configuration.md).

Для обычной игры команды не нужны. Просмотр доступен всем:

```text
/fdc active
/fdc next
/fdc list
/fdc history
```

Для немедленного включения конкретного испытания с читами или OP 2:

```text
/fdc activate no_sprint
```

Все команды также доступны через `/cursecycle`. [Полный справочник](docs/commands.md) · [Быстрая проверка механик](docs/quick-testing.md).

## Сборка из исходников

Нужен JDK 21. Используйте Gradle Wrapper из репозитория: он задаёт Gradle 8.10.2, отдельная установка Gradle не нужна.

```powershell
.\gradlew.bat build
```

Результат: `build/libs/curse-cycle-1.0.5.jar`. На Linux/macOS используйте `./gradlew build`. Первый запуск загружает зависимости; `--offline` подходит только после заполнения кэша.

[Разработка, архитектура и проверки](docs/development.md) · [Вся документация](docs/README.md).

## Если игра не запускается

`Exit code: 1` — общий код завершения. Смотрите `logs/latest.log` в папке запущенного профиля и, если создан, последний файл в `crash-reports/`.

Сообщение о недостающем `fabric-api` означает, что Fabric API не обнаружен именно в этом профиле. Проверьте папку `mods` и совместимость JAR с Minecraft 1.21.1.

Curse-Cycle пишет версии среды и этапы инициализации в лог с меткой `[Curse-Cycle]`. При исключении внутри инициализации создаётся `logs/cursecycle-startup-error.txt` с этапом и цепочкой ошибки. Проверяйте дату внутри файла: старый отчёт сохраняется после успешного запуска. Ошибки зависимостей или Mixin могут возникнуть раньше этого обработчика — в таком случае нужен основной лог Fabric.
