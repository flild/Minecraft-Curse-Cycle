# Добро пожаловать на Луну — правила и проверки

[Документация](README.md) · [Список испытаний](challenges.md) · [Разработка](development.md)

`low_gravity`, MEDIUM/GLOBAL. Игроки Survival/Adventure и мобы прыгают выше, медленнее падают и сильнее отлетают. Игровой список получает название, описание и правила из `ModChallenges` без отдельного списка ID в UI.

## Физика и совместимость

- Гравитация ×0,25, атрибут силы прыжка ×1,25. Ванильные отслеживаемые атрибуты передают собственные временные модификаторы клиенту. Дополнительного умножения гравитации/прыжка в Mixin нет. Чужие базовые значения и модификаторы сохраняются; Jump Boost добавляется ванильным способом после атрибута прыжка.
- Обычный удар (`LivingEntity.takeKnockback`) получает силу ×1,5 до сопротивления. Ванильный предел вертикального импульса на земле 0,4 сохраняется; в воздухе этот путь не добавляет вертикальную скорость. Punch стрел и импульс взрыва масштабируются отдельно ×1,5 после их ванильного расчёта. Вектор взрыва для S2C совпадает с серверным. Уже накопленная скорость не умножается. Обычные столкновения, течение, команды перемещения и отдача `attack_recoil` не усиливаются.
- Вода, лава и элитры используют изменённую ванильную гравитацию со своими коэффициентами. Малые скорости в воде по-прежнему округляются до −0,003, спринт-плавание сохраняет ванильное исключение. Slow Falling ограничивает итог атрибута сверху величиной 0,01 при спуске; второго ×0,25 после этого предела нет. Levitation и NoGravity сохраняют собственную механику.
- В паре с `gravity_ten` у игрока гравитация ×0,75 от базовой без Slow Falling, а с Slow Falling при обычной базе — 0,03 после старого множителя ×3. Мобы не получают `gravity_ten`. Его множитель урона от падения игрока сохраняется. `heavy_body` умножает обычный импульс прыжка после атрибута, `auto_jump` использует тот же прыжок, `no_jumping` по-прежнему отменяет его.
- Само `low_gravity` не меняет урон от падения, безопасную высоту и уже накопленные fallDistance/скорость. Высокий прыжок может закончиться уроном. У летающих/водных видов сохраняются их ванильные способы движения: испытание не заставляет летучую мышь ходить или рыбу прыгать как наземного моба.

## Применимость и очистка

`LowGravityChallenge.reconcile` вызывается серверным обычным тиком LivingEntity и событием ENTITY_LOAD. Для уже загруженных мобов включение/снятие действует на следующем обычном тике, для новых и загруженных из NBT — до первого тика. Нет обхода всех миров, chunk tickets, таблицы UUID или работы, повторённой на каждого игрока. Проверка постоянной сложности на сущность; атрибут меняется только при добавлении/снятии своего ID.

Игроки используют `ChallengeActivity`, включая PERSONAL. Creative/Spectator, мёртвые, удалённые, пассажиры и игроки с полётом abilities исключены. Мобы получают правило только из GLOBAL; PERSONAL одного игрока не меняет мир для остальных. Выключенный ID не применяется. На клиенте источником физики служат серверные атрибуты, а не PERSONAL IDs локального наблюдателя. Ванильная доставка пакетов остаётся асинхронной.

Start/join/respawn сверяют игрока сразу; stop/leave снимают только два собственных модификатора. Обычный тик также исправляет режим, disable/reset/смену state/активации. Временные модификаторы отсутствуют в entity NBT: выгруженный моб не несёт старую лунную физику в следующую загрузку. ENTITY_LOAD выбирает текущее состояние после окончания/рестарта. Другие атрибуты, экипировка, зелья, HP и импульс не откатываются.

Производственные файлы: `LowGravityChallenge`, `LowGravityLivingEntityMixin`, `LowGravityProjectileMixin`, `LowGravityExplosionMixin`, один ENTITY_LOAD callback, регистрация и общий Mixin config. Новых C2S/собственных S2C, ассетов и зависимостей нет. Сервер не загружает клиентские классы для этой механики.

## Воспроизводимые команды

Из корня репозитория:

```powershell
.\gradlew.bat runGametest --offline -I src/gametest/low-gravity.init.gradle
.\gradlew.bat runClient --offline -I src/clientprobe/low_gravity/init.gradle
.\gradlew.bat build --offline
.\gradlew.bat build -x test processGametestResources --offline
git diff --check
git diff --cached --check
```

GameTest XML: `build/low-gravity-gametest/report.xml`. Клиентский маркер: `LOW_GRAVITY_CLIENT_PASSED`. Init GameTest выбирает восемь новых тестов и регрессии GravityTen/HeavyBody/AutoJump/AttackRecoil/Pacifist; остальные GameTest этим запуском не проверяются. После адресного запуска восстановить и сверить полный `build/resources/gametest/fabric.mod.json`.

## Границы автоматических проверок

GameTest проверяет реальный серверный travel/jump/knockback, реальные жидкости, Punch и расчёт взрыва, ванильный codec атрибутов, серверные lifecycle и NBT в одной JVM. Клиентская проба вызывает настоящий `ClientPlayNetworkHandler.onEntityAttributes` и трансформированные travel/jump/knockback с реальным контейнером атрибутов; мир, коллизии и некоторые accessor-методы синтетические. Это не два настоящих сетевых клиента и не обычная игровая сессия.

Ручные сценарии: `/fdc activate low_gravity`, затем `/fdc activate "double_challenge:low_gravity,gravity_ten"`. Сравнить прыжок/спуск игрока и наземного моба, внешний атрибут и Jump Boost/Slow Falling, удар/Punch/взрыв, разные режимы и транспорт. Проверить двух клиентов с входом в tracking range, настоящий портал, выгрузку/чтение файла чанка после конца испытания, полный рестарт JVM и нагрузку с большим числом мобов. Для завершения переключиться на другое испытание; `/fdc stop` отсутствует. До выполнения этих сценариев не считать их пройденными.
