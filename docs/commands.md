# Команды Curse-Cycle

[Документация](README.md) · [Список испытаний](challenges.md) · [Быстрая проверка](quick-testing.md)

У всех команд два равнозначных префикса: `/fdc` и `/cursecycle`. Они относятся к общему состоянию мира. Отдельной команды назначения персонального испытания сейчас нет.

## Просмотр

Эти команды доступны без прав оператора.

| Команда | Результат |
| --- | --- |
| `/fdc active` | Текущие глобальные испытания |
| `/fdc next` | Выбранное следующее испытание или сообщение, что оно ещё не выбрано |
| `/fdc list` | Все зарегистрированные испытания, их ID, сложность и статус включения |
| `/fdc history` | История выпадений с номером игрового дня |

## Изменение состояния

Нужны читы в одиночной игре или права оператора уровня 2 на сервере. В серверной консоли начальный `/` не требуется.

| Команда | Действие |
| --- | --- |
| `/fdc trigger_spin` | Выбирает следующее испытание и показывает колесо. В обычном цикле сохраняет действующее испытание и срок смены. Во время первой подготовки запускает первое колесо сразу |
| `/fdc activate_next` | Немедленно включает сохранённый результат колеса и начинает новый полный интервал |
| `/fdc activate <id>` | Заменяет текущие испытания указанным и начинает новый полный интервал; Tab предлагает включённые ID |
| `/fdc setday <день>` | Устанавливает начало указанного дня мира, начиная с 1, и сразу обрабатывает расписание; может вызвать автоматическую смену |
| `/fdc reset` | Снимает текущие ограничения, очищает историю, пул и состояние цикла, переводит время мира на начало первого дня и запускает подготовку заново |

Повторный `trigger_spin` заменяет сохранённый выбор. Для подтверждения уже выбранного результата используйте `activate_next`. Во время первой подготовки результат первого колеса активируется автоматически через 100 серверных тиков, даже если клиент пропустил анимацию.

При неизвестном или отключённом ID ручная активация отклоняется без завершения текущих испытаний. `activate_next` без доступного результата тоже сохраняет текущую игру.

Ручная активация завершает глобальные и персональные ограничения, очищает старое следующее испытание и начинает новый отсчёт от текущего времени мира. История сохраняется, время суток не перематывается. Утраченные здоровье, предметы и блоки не восстанавливаются.

## Примеры

Включить испытание без ожидания:

```text
/fdc activate heavy_body
```

Выбрать колесом и затем немедленно применить результат:

```text
/fdc trigger_spin
/fdc activate_next
```

Два конкретных испытания — весь составной ID в кавычках:

```text
/fdc activate "double_challenge:no_sprint,no_jumping"
```

Для случайной пары:

```text
/fdc activate double_challenge
```

Само двойное и его компоненты должны быть включены. Для проверки завершения одного испытания обычно достаточно заменить его на `no_sprint`. Команды `/fdc stop` и `/fdc reload` отсутствуют; `reset` нужен для сброса цикла, а не для обычного переключения.
