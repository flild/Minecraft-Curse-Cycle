# crafting_tax — Крафт по талонам

Minecraft 1.21.1 / Yarn 1.21.1+build.3 / Fabric API 0.102.0+1.21.1.
EASY/GLOBAL. Цена — один уровень за исполнение рецепта 2×2/3×3.

## Реализация

- `CraftingTaxResultSlotMixin` переопределяет унаследованный `canTakeItems`:
  проверка до выдачи для обычных кликов, цифр/F и выбрасывания. Оплата через
  `PlayerEntity.addExperienceLevels(-1)` в единственном `onTakeItem`, который
  расходует комплект ингредиентов и обрабатывает возвратную тару. Статистические
  `onCrafted` / `onQuickTransfer` не списывают уровни.
- `CraftingTaxQuickMoveMixin` проверяет уровень и место перед каждым вызовом
  `quickMove` у обоих обработчиков. Ванильный цикл shift-click проверяет
  `canTakeItems` только перед первым исполнением; одна проверка слота недостаточна.
  При частичном размещении vanilla может выбросить остаток результата, поэтому
  здесь сначала требуется место под весь выход одного исполнения. Складывание
  в несколько неполных стеков разрешено. Учитываются слоты inventory_lockdown.
- Все операции выполняются последовательно на серверном потоке. Между допуском,
  выдачей, оплатой и ванильным расходом ингредиентов нет отложенной задачи.
  Никаких возвратов снимков инвентаря или XP, дополнительных пакетов и клиентских
  классов нет. Штатный обработчик сетевого клика согласует слоты, штатный игрок
  синхронизирует изменившийся опыт.
- Активность проверяется заново для каждого действия, включая GLOBAL/PERSONAL,
  включённость, режим и жизнь игрока. Платёжные кредиты и счётчики не нужны:
  XP хранится самим Minecraft, активность — существующим CurseCycleState.
  Временная серверная карта UUID/activationSerial хранит только задержку подсказки;
  выход/респаун/завершение очищают её, объекты игроков в ней не удерживаются.
- Другие станции не используют эти обработчики ручного крафта. Рецепты,
  наковальня, XP за плавку и автоматический Crafter не изменялись.

Порядок вызовов проверен по байткоду установленного Minecraft этой версии.
Сигнатуры сверены с [документацией Yarn CraftingResultSlot](https://maven.fabricmc.net/docs/yarn-1.21.1+build.3/net/minecraft/screen/slot/CraftingResultSlot.html).

Команды: `.\gradlew.bat build`, затем `.\gradlew.bat build runGametest`.
Итог: BUILD SUCCESSFUL (36 s для первой сборки; 1 m 9 s для итоговой сборки
с игровыми тестами). XML: 86 JUnit, 28/28 GameTest, failures/errors/skipped = 0.
Все четыре новых GameTest прошли. `git diff --check` — без ошибок.
Кэш Gradle потребовал доступ вне песочницы: первоначальная попытка получила
`FileNotFoundException` для `F:\Programs\GradleCache\wrapper\dists\gradle-8.10.2-bin\a04bxjujx95o3nb99gddekhwo\gradle-8.10.2-bin.zip.lck`
с отказом в доступе. Зависимости и окружение не менялись.

JUnit `CraftingTaxChallengeTest` проверяет регистрацию, EASY/GLOBAL, отсутствие
дубликата, пул/выключение и NBT round trip GLOBAL/PERSONAL/double без собственного
сохраняемого состояния налога.

Четыре новых сценария `CraftingTaxGameTest` запускаются на сервере с настоящими
Mixin, рецептами, ServerPlayerEntity и ScreenHandler:

- Нулевой уровень с неполной полоской, левый/правый клик, shift, цифры/F,
  выбрасывание, отрицательные случаи double-click/clone; четыре доски за один
  уровень, неизменность дробного прогресса и vanilla totalExperience.
- Повторный настоящий ClickSlotC2SPacket со старой ревизией после расхода
  единственного бревна: один результат и один платёж. Это не античит и не
  запрет законных повторных крафтов в том же тике.
- Курсор с недостаточным/точным местом, несовместимый занятый swap;
  shift в обеих сетках до лимита XP/места, полный инвентарь, частичное место,
  размещение в двух неполных стеках. Настоящий рецепт торта возвращает три ведра;
  при отказе торт, молоко и ингредиенты не расходуются.
- Книга рецептов на уровне 0, результат печи без налога,
  сочетание с inventory_lockdown и запрет использования закрытых слотов.
- Команды `/fdc list`, `/fdc activate crafting_tax`, `/fdc active`;
  Creative, применимость Spectator/Adventure/Survival, поздний вход, персональный
  ID и дублирование GLOBAL/PERSONAL, выключение испытания, мёртвый объект,
  замена сущности при респауне, телепортация Nether/Overworld, запись/чтение
  общей активности на диске, повторное подключение того же UUID и завершение
  офлайн. Сочетания no_sprint и bitter_experience: оплата не наносит урон.
- Настоящий actionbar GameMessageS2CPacket: одно сообщение при повторных
  отказах в одном тике, отсутствие на тике 39, повтор на тике 40.

Первый прогон выявил две ошибки подготовки новых тестов: мировой контекст
верстака отсутствовал, а перехват подсказки ожидал OverlayMessage вместо
GameMessage с overlay=true. Оба стенда исправлены перед итоговым прогоном.

## Ручная проверка — не выполнена

1. В настоящем клиенте выполнить `/fdc activate crafting_tax`; проверить название,
   полные правила в меню/HUD и видимую подсказку «Нужен 1 уровень опыта».
2. В личной сетке при уровне 1 забрать четыре доски, на уровне 0 повторить.
   Повторить на верстаке: уровень 2, три бревна, shift → 8 досок, одно бревно
   остаётся. Проверить цифры, F, Q/Ctrl+Q, двойной клик, перетаскивание,
   полный/частично заполненный курсор, быстрые последовательности и книгу рецептов.
3. Полный инвентарь и рецепт торта: отказ не расходует ингредиенты/молоко/XP;
   после освобождения места один торт стоит уровень, ведра возвращаются.
   Проверить видимую синхронизацию XP и инвентаря при задержке соединения.
4. Проверить все остальные перечисленные в ТЗ станции и автоматический Crafter.
   Автотест отдельно исполняет только получение результата печи; отсутствие
   налога на остальных следует из области Mixin, а не из их игрового прогона.
5. Реальная смерть с keepInventory=false/true, экран возрождения, порталы,
   выход/вход с загрузкой инвентаря и XP, полный перезапуск процесса сервера
   при активном испытании и после завершения офлайн. Автотест повторно подключает
   UUID, но задаёт XP и материалы заново; общая активность читается с диска
   в том же процессе. Телепортация не заменяет проверку порталов.
6. Два настоящих клиента на выделенном сервере: независимая оплата и подсказки,
   уход одного не влияет на другого. Проверить сочетание с blind_hud.
   Проверка Spectator/Adventure в стенде подтверждает применимость; штатные
   ограничения этих режимов на открытие/использование интерфейсов сохраняются.

Для завершения активировать `/fdc activate no_sprint`: будущие крафты бесплатны,
потраченные уровни не возвращаются, no_sprint продолжает действовать.
Команды `/fdc stop` нет.
