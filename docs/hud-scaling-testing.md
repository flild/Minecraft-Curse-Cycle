# Масштабирование HUD

Проверено 20.11.2026. Общая плашка испытаний, heartbeat и выносливость используют
масштаб `min(1, ширина GUI / 640, высота GUI / 360)`. Процент размера HUD из настроек
дополнительно применяется к общей плашке. Сохранённые координаты остаются в единицах GUI.

При области GUI 320×240 общая плашка имеет ширину 101 вместо 202 единиц,
heartbeat — 90 вместо 180. Текст, значки и рамки уменьшаются вместе.
Длинная подпись heartbeat переносится внутри панели; её высота учитывает число строк.
Отступы снизу сохраняются в единицах GUI, чтобы heartbeat и выносливость оставались
выше хотбара и шкал Minecraft и не пересекались друг с другом.

## Автоматическая проверка

```powershell
.\gradlew.bat build --offline --console=plain
.\gradlew.bat runClient --offline --console=plain -I src/clientprobe/visual/init.gradle -PhudScaleProbe
```

- Сборка прошла; 218 JUnit-тестов, без падений, ошибок и пропусков.
- Три новых теста проверяют долю ширины экрана, сохранение обычного размера при
  достаточном месте, дополнительное уменьшение настройкой и размещение полос.
- Изолированный клиент с настоящим OpenGL завершился с
  `CURSECYCLE_HUD_SCALE_PROBE_PASSED checks=9`.
- GUI Scale 6 подтверждён через `Window.getScaleFactor()` при 2560×1440 и 1920×1440.
- Получены пять кадров: GUI 2 при 1280×800, оба разрешения GUI 6,
  длинная искусственная подпись клавиши в GUI 6 и окно 854×480 при GUI 2.
- Кадры GUI 6 с длинной подписью и маленького окна просмотрены: текст помещается,
  полосы разделены, рамка выносливости вмещает заполнение.
- Клиентский пробник находится вне production source set и отсутствует в JAR мода.

## Границы проверки

Кадры получены на тестовом экране с настоящими методами отрисовки HUD и ванильными
спрайтами хотбара и прицела. Мир не загружался: живой ввод heartbeat, получение урона,
сетевая синхронизация и совместимость с HUD сторонних модов этим прогоном не проверялись.
Серверные механики, пакеты и правила видимости HUD не менялись.

Для проверки в мире включить heartbeat и heavy_body, выбрать GUI 6, проверить обычный
ритм, подготовку, попадание и истощение, затем переключить F1 и размер HUD в H → Настройки.
